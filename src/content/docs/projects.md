PHP Ecosystem brings three project collections maintained by Wilmer Arambula
together with a separate community catalog. Each package keeps its own
repository, license, requirements, and maintainer attribution.

## Yii2 Extensions

Integrations and development tools for applications in the Yii2 ecosystem.
Package documentation provides the exact supported framework and PHP versions;
the collection name does not imply support for every Yii release.

Start with the [Bootstrap 6](extensions/bootstrap6/index.md),
[FilePond](extensions/filepond/index.md), and
[Inertia](extensions/inertia/index.md) guides, or explore the
[Yii2 Extensions repositories](https://github.com/yii2-extensions).

## PHP Forge

PHP libraries and development tooling with their own dependency contracts.
Check the individual package before choosing it for a framework integration.

Explore the [PHP Forge repositories](https://github.com/php-forge) and the
evidence recorded in the [package catalog](/docs/packages/).

## UI Awesome

PHP tools for HTML and user interfaces. Components, themes, and supporting
libraries remain distinct packages with separate requirements.

Explore the [UI Awesome repositories](https://github.com/ui-awesome) and compare
their requirements in the [package catalog](/docs/packages/).

## Community

Community entries belong to their named maintainers. They are separate from the
three collections above, even when they solve similar problems or work with the
same framework.

The catalog accepts proposals for Yii2, Yii3, and framework-independent PHP
packages. [Propose an extension or library](contribute.md) with its source,
license, documentation, and compatibility evidence. A listing records reviewed
metadata; it is not a security certification or a promise of support by this
site's maintainer.

For framework documentation, use the [documentation gateway](documentation.md).
For the site's ownership and professional work, read [About](about.md).
