Use the official Yii3 resources for framework guidance. This portal provides a
separate place to discover packages and review their declared compatibility.

## Official resources

| Resource                                                            | Use it for                                            |
| ------------------------------------------------------------------- | ----------------------------------------------------- |
| [Yii3 guide](https://yiisoft.github.io/docs/guide/)                 | Application concepts and development workflows        |
| [Yii3 API reference](https://www.yiiframework.com/doc/api/3.0)      | Package APIs                                          |
| [Yii3 community cookbook](https://yiisoft.github.io/docs/cookbook/) | Recipes contributed to the Yii3 documentation project |

These are external resources linked by the
[official Yii website](https://www.yiiframework.com/). The portal does not maintain
a copy of the Yii3 manual or represent the Yii team.

## Find a package for your application

Use the Yii3 filter in the [package catalog](/docs/packages/). Each entry records
its own PHP requirement, compatibility evidence, and inspected source. Read that
evidence alongside the upstream documentation before choosing a package.

Yii2 and Yii3 are distinct ecosystems. Neither membership in a project collection
nor framework-independent PHP code establishes compatibility with a specific
Yii3 integration. A lack of listings means the catalog has no reviewed entry for
that selection; it is not a statement about the availability of packages elsewhere.

## Contribute a Yii3 extension

[Propose a package](../contribute.md) with its repository, license, documentation,
PHP constraint, and the exact Yii3 dependencies or integration evidence. Record
the release or commit that the evidence describes. Community authors keep their
own attribution and support channels.
