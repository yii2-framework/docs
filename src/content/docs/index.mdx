Useful packages, with the context to use them. Explore Yii2 Extensions, PHP Forge
and UI Awesome alongside a curated community catalog. Curated by Wilmer Arambula
(terabytesoftw), this independent portal is not an official Yii website.

## Explore packages

[Browse the package catalog](/docs/packages/index.md) for Yii2, Yii3 and reusable
PHP libraries. Each record identifies its maintainer, literal PHP and framework
requirements, license, and inspected source revision. A source snapshot does not
establish a latest published release or every tested combination.

## Collections

Three [collections](projects.md), Yii2 Extensions, PHP Forge and UI Awesome,
cover application features, package development and interface building blocks.
Community listings retain their own authorship and are distinguished from the
maintained collections.

## Documentation

[Choose documentation](documentation.md), [read the Yii2 guide](guide/index.md),
[look up an API](api/index.md), or [explore Yii3](ecosystems/yii3.md).
