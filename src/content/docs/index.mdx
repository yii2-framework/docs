Yii is a component-based PHP framework for Web applications. These docs cover the 22.0 development line:
PHP 8.3 or newer, Composer autoloading, and application templates with an explicit version constraint.

## Yii2

[Create your first application](guide/start-installation.md), then follow its
[structure and request lifecycle](guide/start-workflow.md). Start with a working project and add controllers,
models, forms, and tests as you need them.

- [Read the guide](guide/index.md) for concepts and practical examples;
- [look up an API](api/index.md) for signatures, defaults, and inherited members.

## Extensions

Add features using the package guides and API references in the Extensions navigation. Each guide comes from its
package repository and includes installation, configuration, and examples.

- [FilePond](extensions/filepond/index.md) for file uploads;
- [Locale URLs](extensions/localeurls/index.md) for language-prefixed URLs.

Bootstrap 6 widgets are also available in local previews when their package sources are present. The package is
marked unpublished; its guide appears in navigation only when included in the build.

## AI

[Connect your coding agent](project/ai-agents.md) to the Yii application skills. Install only the skills your
application needs, follow its code standards, and fetch the relevant Markdown pages or API entries for each task.

The AI guide explains setup for Codex, Claude Code, OpenCode, GitHub Copilot in VS Code, and Amp, including what has
actually been tested.
