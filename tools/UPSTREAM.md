# Patches worth sending to yiisoft/yii2-apidoc

`tools/bin/reference` uses yii2-apidoc 4.0.1 as parser and link model without forking it. The gaps below are worked
around in `src/` (file in parentheses); each is a small upstream patch that would let the workaround go.

| #   | Gap in 4.0.1                                                                                                                                   | Effect                                                                                        | Workaround here                                                                                                                       |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | `TypeDoc::findSubject()` reads `$subjectName[0]` after stripping the namespace; an empty `{@see}` makes it `''`.                               | Run aborts with `Uninitialized string offset 0` (bootstrap6 `OtpInput.php`).                  | Own link resolver (`Link/LinkResolver.php`); an empty target is counted as unresolved.                                                |
| 2   | `PropertyDoc` takes the summary from the `@var` description only, overwriting the docblock summary.                                            | 112 properties lost their description (bootstrap6 house style puts the summary above `@var`). | Summary fallback from reflection; only warnings disproved by recovered property descriptions are removed (`Model/ModelRepairer.php`). |
| 3   | `Context::parseFile()` never reads `File::getEnums()`; there is no `EnumDoc`.                                                                  | Enums have no page, no cases, and links to them break.                                        | `Model/EnumDoc.php`, `Model/ReferenceContext.php`.                                                                                    |
| 4   | Promoted constructor properties keep neither the constructor `@param` description nor its PHPDoc type; private constructors are skipped.       | Empty descriptions, `array` instead of `array<string, mixed>`.                                | `Model/ModelRepairer.php` (65 descriptions, 25 types repaired).                                                                       |
| 5   | No `readonly` flag on classes and properties; promoted properties are not marked.                                                              | `final readonly class` shown as `final class`.                                                | Flags recorded from the reflectors (`Model/ModelRepairer.php`).                                                                       |
| 6   | `Context::getReflectionProject()` parses every file again on each call.                                                                        | A second call costs the full parse time.                                                      | Cached in `Model/ReferenceContext.php`.                                                                                               |
| 7   | Relative link targets are resolved with the class docblock context (`phpDocContext`), which is `null` when the class has no docblock.          | Every relative link of such a class breaks.                                                   | Imports read from the file (`ContextFactory::createForNamespace()`).                                                                  |
| 8   | `@property-read`/`@property-write` together with a getter/setter raise `Property $X conflicts with a defined getter` and lose the access mode. | 1149 framework errors; read-only/write-only state lost.                                       | Tags bind to accessors without changing declared fields (`Model/ReferenceContext.php`); access recorded from tags.                    |
| 9   | Descriptions come from `Description::render()`, which turns `{@see begin()}` into `{@see \ns\begin()}`.                                        | Member references in descriptions resolve as functions and break.                             | Last segment retried as a member of the context (`Link/LinkResolver.php`).                                                            |
| 10  | Private and `@internal` constants are documented.                                                                                              | Implementation details on public pages.                                                       | Removed before inheritance (`Model/ModelRepairer.php`).                                                                               |
| 11  | `ParamDoc` has no variadic flag.                                                                                                               | `...$args` shown as `$args`.                                                                  | Read from the reflection arguments (`Model/TypeReader.php`).                                                                          |
| 12  | `TypeDoc::__construct()` documents `Class_\|Interface_\|Trait_` although `Enum_` works.                                                        | Static analysis error for enum support.                                                       | `ignoreErrors` entry in `phpstan.neon`.                                                                                               |

The Markdown and JSON output does not use `ApiMarkdown`: the docblock text is already Markdown, so references are
rewritten in place (`Render/DocText.php`) instead of rendering HTML and converting it back.
